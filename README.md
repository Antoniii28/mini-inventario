## Flujo de trabajo
1. Crear una rama desde `main` (`feature/...`, `fix/...`, `docs/...`).
2. Hacer commits pequeños y descriptivos.
3. Abrir un Pull Request y pedir revisión al otro integrante.
4. Fusionar a `main` solo después de la aprobación.
