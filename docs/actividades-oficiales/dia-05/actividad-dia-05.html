Prueba tu app con los ojos del agente

Primero el agente usa tu aplicación en un navegador real, toma capturas y reporta problemas. Después conviertes ese recorrido en pruebas que se pueden repetir.

Duración: 60 minutosModalidad: individual

Antes de empezar

  • La web conectada a Supabase.
  • Un usuario confirmado para pruebas.

Qué tienes que hacer

  1. Instala las herramientas10 min

    Crea la rama dia-05-pruebas. Agrega TEST_EMAIL y TEST_PASSWORD a tu .env, y luego instala playwright-cli. Después instala su skill con el comando de tu agente indicado abajo y reinicia la sesión del agente.

    Terminal
    npm install -g @playwright/cli@latest
playwright-cli --help

  2. Deja que el agente explore15 min

    Si no sabe cómo hacerlo, comandos útiles son open, resize, screenshot y console.

    Prompt para tu agente
    Arranca la app. Usa playwright-cli para abrir http://localhost:3000, iniciar sesión con TEST_EMAIL y TEST_PASSWORD de .env sin mostrarlos, y agregar un producto con cantidad menor al mínimo. Toma capturas en 1280x800 y en 390x844, y revisa los errores de consola. Guarda las capturas en entregas/dia-05/ y reporta lo que encontraste. No corrijas nada todavía.

  3. Elige un problema5 min

    Revisa las capturas tú mismo. Elige un problema real, sea funcional o visual, y pide corregirlo.

  4. Crea pruebas permanentes20 min

    Instala Playwright Test con npm init playwright@latest y después pide las pruebas.

    Prompt para tu agente
    Escribe pruebas de Playwright en tests/ para: iniciar sesión, rechazar una contraseña incorrecta, agregar un producto y marcar un producto bajo el mínimo. Lee TEST_EMAIL y TEST_PASSWORD del entorno. Cada prueba usa un SKU único y borra lo que creó. Configura webServer para arrancar la app. Corre las pruebas y muéstrame el resultado.

  5. Demuestra que detectan errores10 min

    Cambia a mano la comparación del producto bajo el mínimo, corre las pruebas y confirma que fallan. Revierte el cambio, confirma que pasan y abre el pull request.

    Terminal
    npx playwright test

Qué entregas

Enlace al pull request, con capturas y entregas/dia-05/README.md.

  • Los prompts clave que usaste.
  • Un error o una mala decisión de la IA, y cómo lo detectaste.
  • Un comando o herramienta que aprobaste o rechazaste, y por qué.
  • Cómo comprobaste que funciona.

Si te atoras

Si faltan navegadores o dependencias, ejecuta npx playwright install --with-deps chromium.

Si terminas antes

Agrega una prueba de edición y otra para campos vacíos.
