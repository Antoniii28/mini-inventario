Conecta datos reales e inicio de sesión con Supabase

Hoy reemplazas el almacenamiento temporal por una base de datos real. El agente trabaja mediante el MCP de Supabase y tú apruebas cada cambio.

Duración: 60 minutosModalidad: individual

Antes de empezar

  • La primera versión de la web en la rama principal.
  • Una cuenta gratuita de Supabase.

Qué tienes que hacer

  1. Crea tu proyecto10 min

    En Supabase crea un proyecto llamado mini-inventario y copia su Project Ref desde la configuración. Crea en tu repositorio la rama dia-04-supabase.

  2. Conecta el MCP y las skills10 min

    Usa los comandos de tu agente indicados abajo. Conecta el MCP solo a tu proyecto y autoriza desde el navegador. Mantén la aprobación manual: el MCP actúa con tus permisos de desarrollador. Después instala las skills supabase y supabase-postgres-best-practices y reinicia la sesión del agente.

  3. Crea la tabla y sus reglas15 min

    Lee el SQL completo antes de aprobarlo.

    Prompt para tu agente
    Usa el MCP de Supabase solo en este proyecto y sigue las skills supabase y supabase-postgres-best-practices. Crea una migración con la tabla productos según docs/diseno.md. Activa Row Level Security y crea políticas para que cada usuario solo pueda leer, crear, editar y borrar sus propios productos. Muéstrame el SQL antes de aplicarlo.

  4. Conecta la web15 min

    En Supabase, ve a Authentication, Users y crea 2 usuarios confirmados para no depender de correos.

    Prompt para tu agente
    Cambia public/productos.js para usar Supabase en lugar de localStorage. Agrega registro e inicio de sesión con correo y contraseña. Lee SUPABASE_URL y SUPABASE_KEY del archivo .env y entrégalas al navegador desde la ruta /config.js. Usa solo la llave publishable o anon, nunca la service_role. Crea un .env.example sin valores.

  5. Comprueba la seguridad y abre el PR10 min

    Entra con cada usuario y confirma que ninguno ve los productos del otro. Toma una captura de cada sesión. Comprueba que .env no se sube y abre el pull request.

    Terminal
    git status
git check-ignore .env
